---
description: Push project updates to GitHub
---

This workflow helps you quickly stage, commit, and push your changes to GitHub.

1. **Check if Git is initialized**
   If you haven't run `git init` yet, run it once in your terminal.

2. **Stage all changes**
   // turbo
   `git add .`

3. **Commit with a message**
   Run the following command, replacing "Your message" with a description of what you changed:
   `git commit -m "Your message"`

4. **Push to GitHub**
   // turbo
   `git push origin main`

*Note: If this is your first time pushing, make sure you have linked your remote repository using `git remote add origin <URL>`.*
